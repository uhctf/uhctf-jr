# Dag van de Wetenschap

- Doelgroep: families, kinderen en jongeren
- Formaat: booth: vrij in- en uitstappen, korte uitdagingen
- Duur: 15 minuten per sessie
- Datum / locatie: 23/11/2025, UHasselt

## Uitdagingen

De uitdagingen staan in [uitdagingen.toml](uitdagingen.toml) (alle met standaardantwoord). Bouw de pdf's met `./jr event build dag-van-de-wetenschap`.

Gebruikt in 2025:

| Uitdaging | Moeilijkheid | Punten |
| --- | --- | --- |
| [Doolhof](../../challenges/doolhof/) | makkelijk | 50 |
| [Woordzoeker](../../challenges/woordzoeker/) | makkelijk | 50 |
| [Romeinse geheimen](../../challenges/romeinse-geheimen/) | makkelijk | 50 |
| [De verloren uitdaging](../../challenges/verloren-uitdaging/) | makkelijk | 50 |
| [Robot-QR](../../challenges/robot-qr/) | gemiddeld | 100 |
| [Kraak de code](../../challenges/kraak-de-code/) | gemiddeld | 100 |
| [Laag na laag](../../challenges/laag-na-laag/) | gemiddeld | 100 |
| [Webvlaggen](../../challenges/webvlaggen/) (web 1 / 2 / 3) | gemiddeld / moeilijk / extreem | 100 / 150 / 200 |

## Materiaal

- laptops
- afdrukken: de `deelnemer.pdf`'s van `./jr event build dag-van-de-wetenschap` (doolhof, woordzoeker, kraak de code, romeinse geheimen, laag na laag) en optioneel de spiekbrief (`spiekbrief/spiekbrief.pdf` in de uitvoer van romeinse geheimen of laag na laag)
- de 3D-geprinte robot met QR-code (optioneel). De foto ervan, [robot.jpg](robot.jpg), is de afbeelding in de beeldbewerker van Robot-QR (zie [uitdagingen.toml](uitdagingen.toml))
