# Oplossing

Het bericht begint met het bekende `proficiat agent`. Vergelijk letter per letter: de verschuiving van elke letter is een letter van de sleutel (A = 0, B = 1, ...). Met de standaardwaarden geeft dat `ROBOTROBOTROBO`: de sleutel is **ROBOT**.

Ontcijfer de rest door elke letter terug te schuiven met de sleutelletter eronder (spaties overslaan). Het bericht zegt: "proficiat agent jouw volgende opdracht staat klaar het antwoord voor de kluis is polyalfabetisch vernietig dit bericht".
